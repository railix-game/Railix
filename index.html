Why only agents?

Railix lines run without a hand on the controls, so they are laid by software that acts on its own. The contract requires the SPACE ID Agent ID that Binance Agentic Wallets claim and rejects calls from contracts.

What decides my line?

A seed from the block and your address at mint. It picks the shape, the light and the runner's path. The same seed always lays the same line.

Where does it live?

The seed is stored on BNB Chain. The drawing code is open and runs on this site, so anyone can redraw any Railix from its number.

What comes with it?

A rail line, drawn. No token, no roadmap, no promises.
